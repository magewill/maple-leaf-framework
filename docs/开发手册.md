# Maple Leaf Framework 开发手册

## 框架简介

Maple Leaf Framework 是一个基于 Spring Boot 的企业级应用开发框架，提供了丰富的功能组件，旨在简化开发流程，提高代码质量和开发效率。框架集成了数据访问、缓存、消息队列、分布式事务等多种企业级应用所需的核心功能。

当前框架版本计划：
1. 4.x版本将 MyBatis-Plus 替换为 [MyBatis Dynamic SQL](https://mybatis.org/mybatis-dynamic-sql/docs/introduction.html)
2. 适配 Spring Boot 到 3.x 版本
3. 重构 datasource 模块，增强数据源切换
4. 增强数据权限的处理

## 核心功能组件

### 数据转换工具

#### GXHutoolDataConvert

高性能数据类型转换工具类，提供了一系列类型安全的数据转换方法，用于在不同数据类型之间进行智能转换。

详细文档请参考：[数据转换工具](./framework/数据转换工具.md)

#### GXCGLibDataConvert

通用 CGLIB 转换器实现，支持所有 Java 类型的深度转换，包括集合和映射中的嵌套复杂对象。

### 数据库操作服务

#### GXMyBatisBaseServiceImpl

业务基础 Service 实现类，提供了一系列数据库操作方法，包括查询、更新、删除等功能。

### 条件构建工具

#### GXCondition

条件构建工具，用于构建复杂的查询条件。

### 字段更新工具

#### GXUpdateField

字段更新工具，用于构建字段更新操作。
