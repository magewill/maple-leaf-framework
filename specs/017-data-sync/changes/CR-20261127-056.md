# CR-20261127-056：Canal RabbitMQ 链路适配 AMQP 1.0

- 类型：`task`
- 状态：`applied`
- 影响：`leaf-base-data-sync` 的 RabbitMQ 链路（`GXCanalConfig`、`GXCanalRabbitMQListener`、`GXCanalRabbitMQFailureHandler` 及其测试）；`AGENTS.md`；`docs/leaf-base-data-sync开发手册.md`
- 日期：2026-11-27
- 关联命令：manual
- 原始记录位置：Session 2026-11-27（依赖 CR-20261127-055）

## 背景 / 现象

`leaf-base-rabbitmq` 迁移到 AMQP 1.0（CR-20261127-055）后不再传递依赖 `spring-rabbit`，
`leaf-base-data-sync` 中基于 `RabbitTemplate` / `RabbitAdmin` / `@RabbitListener` /
`SimpleRabbitListenerContainerFactory` 的 Canal 链路无法编译。

## 变更前

- `GXCanalConfig` 声明 `Queue` / `Exchange` / `Binding` Bean，依赖 `RabbitAdmin` 自动声明。
- `GXCanalRabbitMQListener` 用 `@RabbitListener(bindings = @QueueBinding(...), concurrency = ...)` 消费，
  失败语义依赖容器 `defaultRequeueRejected` 与 `AmqpRejectAndDontRequeueException`。
- `GXCanalRabbitMQFailureHandler` 用 `RabbitTemplate#send` 原样重投。
- 测试断言 `Queue`/`Exchange` Bean 与 `RabbitListenerEndpointRegistry`。

## 变更后

- `GXCanalConfig` 改为在 `canalRabbitTopology` Bean 工厂方法中通过 `GXSendRabbitMQService` 声明
  DLX/DLQ、主交换机、带死信参数的队列与绑定，并返回 `CanalRabbitTopology` 记录。
  在 Bean 创建期声明，保证监听容器启动前拓扑就绪。
- `GXCanalRabbitMQListener` 改为 `@AmqpListener(addresses = "/queues/<queue>", concurrency = ...)`，
  新增 `onMessage(Message, AmqpAcknowledgment)`：成功 `ACCEPT`、`AmqpRejectAndDontRequeueException`
  子类 `REJECT`、其他异常 `REQUEUE`；保留 `listener(payload, traceId, retryCount)` 供直接调用。
- `GXCanalRabbitMQFailureHandler` 改为 `GXSendRabbitMQService#sendRawMessage`（原样重投，不重新序列化），
  并通过 `GXCorrelationData#await` 等待结算：只有 `accepted` 才确认原消息，否则拒绝进死信（避免重投失败静默丢事件）。
- 依赖 `leaf-base-rabbitmq` 新增的 `GXAmqpListenerErrorHandler`：消息体无法转换时直接 reject 进死信，
  避免监听器方法未执行就无限重投。

## 验收标准

- [x] `mvn -o -B -pl leaf-base-data-sync test` 全绿（96 用例，2 个环境门控用例跳过）。
- [x] 真实 RabbitMQ 4.4.1：合法 Canal 载荷被表处理器消费；非法载荷进入 `canal.dlq`。
- [x] 条件装配不变：`canal.consumer-enabled=false` 与 `canal.mq-type=rocketmq` 时不声明拓扑。
- [x] 监听器保持 eager，地址为 AMQP 1.0 v2（`/queues/...`）。

## 兼容性说明

- 拓扑不再由 `RabbitAdmin` 自动声明，而是上下文启动时通过 Management HTTP API 声明；
  需要 Broker 开启 management 插件（默认 15672）。
- 消费地址必须是 `/queues/<queue>`。
- 消息体转换失败现在直接进死信，不再重投；`GXCanalConsumeStatistics` 不统计此类失败。
